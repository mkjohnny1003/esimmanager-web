荒野大對決如何處理遊戲資料

本政策適用於荒野大對決（Wild Showdown）iPhone App 與本網站。

1. App 本機資料

最高分、最高關卡與音效開關保存在裝置本機，不會傳送到我們的伺服器（我們也沒有伺服器）。移除 App 會一併清除這些紀錄，且無法復原。

2. Game Center 排行榜

App 可選擇使用 Apple Game Center。未登入仍能完整遊玩。登入後，每局結束時的分數會送交 Game Center 排行榜，你的暱稱與分數依 Apple 的規則處理與顯示；我們不另外保存這份資料。詳見 Apple 隱私政策。

3. 廣告、追蹤與購買

App 與本網站不含廣告或廣告 SDK，不做跨 App 或跨網站追蹤，也沒有加入任何分析服務。App 沒有應用程式內購買項目，不需要註冊帳號。

4. 系統權限

App 不要求相機、相簿、聯絡人、位置、麥克風或通知權限。

5. 兒童隱私

我們不蒐集任何人的個人資料，包括兒童。

6. 網站服務

網站使用 GitHub Pages 託管，服務供應商可能依其政策處理連線與安全紀錄。請參閱 GitHub 隱私聲明。

7. 聯絡與更新

隱私問題請聯絡 mkjohnny@gmail.com。資料處理方式變更時，會更新上方日期與本頁內容。
