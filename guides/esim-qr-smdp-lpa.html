eSIM 教學中心 / 啟用碼格式

eSIM QR Code、LPA、SM-DP+ 是什麼？

購買旅遊 eSIM 後，供應商通常會寄一張 QR Code、PDF 或一串啟用碼。這些資訊看起來很技術，但概念其實很簡單：它們是讓 iPhone 找到並下載那張 eSIM 設定檔的線索。

QR Code：最常見的啟用入口

多數旅遊 eSIM 會提供 QR Code。iPhone 掃描後，會連到供應商的 eSIM 設定伺服器，下載對應的行動方案。eSIMManager 可以協助保存與解析常見格式的 QR Code，方便你日後查看、整理或分享卡片紀錄。

LPA 字串：QR Code 裡真正重要的內容

有些供應商會提供以 LPA:1$ 開頭的文字，這就是常見的 eSIM 啟用字串。QR Code 很多時候只是把這段文字包起來。當圖片或 PDF 辨識失敗時，你可以嘗試手動貼上完整 LPA 字串。

SM-DP+ 位址與 Matching ID

SM-DP+ 可以理解成供應商用來提供 eSIM 設定檔的伺服器位址；Matching ID 則是用來找到你那筆方案的識別資訊。不同供應商的呈現方式不同，有些會完整列出，有些只包在 QR Code 裡。

為什麼這些資訊要小心保存？

啟用碼可能等同於安裝 eSIM 的鑰匙。若你把完整 QR Code 或 LPA 字串公開給別人，可能造成方案被他人嘗試啟用。eSIMManager 的備份功能預設排除敏感啟用資訊，若你選擇包含啟用碼，請務必加密並妥善保存。

App 能保證安裝成功嗎？

不能。eSIMManager 可以協助整理資料並嘗試開啟 iOS 系統安裝流程，但安裝能否成功，仍取決於 iOS 版本、裝置是否支援 eSIM、網路狀態、啟用碼是否有效，以及供應商系統是否正常。
