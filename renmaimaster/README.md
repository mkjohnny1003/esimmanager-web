# 人脈大師

Card Master（人脈大師）iPhone 名片管理 App 的官方網站。提供繁體中文、英文、日文、韓文的產品介紹、使用支援與隱私政策頁面。

## iOS 1.6／iPhone Duo 正式上架

- 四語首頁（`index.html`、`en/`、`ja/`、`ko/`）已加入 iPhone Duo 專區與對應的模擬器實際畫面；圖片位於 `assets/duo-inner-*.webp`，展示資料為虛構名片。
- 2026-11-03 已核對 Apple 公開商店資料為 1.6；四語首屏、標題／分享摘要、頁尾與支援頁均宣告 iPhone Duo 支援，並清除過期的韓國商店等待文案。
- 正式頁面：`https://getesimmanager.com/renmaimaster/`，英文／日文／韓文分別位於 `en/`、`ja/`、`ko/`。
