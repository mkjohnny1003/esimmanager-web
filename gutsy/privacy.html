GUTSY 如何處理遊戲資料

本政策適用於 GUTSY（腸腸久久）iPhone App 與本網站的網頁試玩版。

1. iPhone App 本機資料

最高分數、已解鎖關卡、音量與畫面設定保存在裝置本機，不會傳送到我們的伺服器。移除 App 會一併清除這些紀錄，且無法復原。

2. Game Center 排行榜

iPhone App 可選擇使用 Apple Game Center。未登入仍能完整單機遊玩。登入後，暱稱與分數依 Apple 的規則處理；我們不另外保存這份 Game Center 資料。詳見 Apple 隱私政策。

3. 網頁試玩與公開排行榜

網頁試玩版的本機進度與暫存分數保存在瀏覽器。每局結束後，只有按下「留下紀錄」才會提交。提交時會將自選玩家名稱、分數、世界與關卡、難度、遊玩時間、是否完成及提交時間存入 Cloudflare D1。排行榜公開顯示最高 20 筆的名稱、分數與關卡。請勿使用真實姓名或其他個人資訊作為玩家名稱。

網頁排行榜與 Game Center 分開，不需要帳號。已提交的紀錄會保留，直到我們依要求移除或停止提供此服務。若要刪除自己提交的紀錄，請來信提供玩家名稱、分數、關卡及大約提交時間，方便我們核對；如無法確認紀錄屬於你，可能無法刪除。

4. 廣告、追蹤與購買

App 與本網站不含廣告，不加入廣告 SDK 或分析程式，也不做跨 App 或跨網站追蹤。App 沒有應用程式內購買項目；遊玩不需要註冊帳號。

5. 系統權限

iPhone App 不要求相機、相簿、聯絡人、位置或麥克風權限。

6. 網站服務

網站使用 GitHub Pages 託管；網頁排行榜使用 Cloudflare Workers 與 D1。服務供應商可能依其政策處理連線與安全紀錄。請參閱 GitHub 隱私聲明與 Cloudflare 隱私政策。

7. 聯絡與更新

隱私問題或排行榜紀錄刪除請聯絡 mkjohnny@gmail.com。資料處理方式變更時會更新上方日期與本頁內容。
